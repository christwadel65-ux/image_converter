# Guide de Contribution

Merci de votre intérêt pour contribuer à image_converter ! 🎉

## Comment contribuer

### Signaler un bug

1. Vérifier que le bug n'a pas déjà été signalé dans les [Issues](https://github.com/christwadel65-ux/image_converter/issues)
2. Créer une nouvelle issue avec le template "Bug Report"
3. Fournir le maximum d'informations :
   - Version du projet
   - Système d'exploitation
   - Étapes pour reproduire
   - Comportement attendu vs obtenu

### Proposer une fonctionnalité

1. Créer une issue avec le template "Feature Request"
2. Décrire clairement la fonctionnalité souhaitée
3. Expliquer pourquoi elle serait utile

### Soumettre une Pull Request

1. Fork le projet
2. Créer une branche (\git checkout -b feature/AmazingFeature\)
3. Committer vos changements (\git commit -m 'feat: add amazing feature'\)
4. Pousser vers la branche (\git push origin feature/AmazingFeature\)
5. Ouvrir une Pull Request

## Conventions de code

### Commits

Nous utilisons [Conventional Commits](https://www.conventionalcommits.org/) :

- \eat:\ nouvelle fonctionnalité
- \ix:\ correction de bug
- \docs:\ documentation
- \style:\ formatage, point-virgules manquants, etc.
- \efactor:\ refactoring de code
- \	est:\ ajout de tests
- \chore:\ maintenance

### Code Style

- Suivre les [conventions C# de Microsoft](https://docs.microsoft.com/en-us/dotnet/csharp/fundamentals/coding-style/coding-conventions)
- Utiliser \dotnet format\

## Tests

- Tous les nouveaux codes doivent être testés
- Les tests doivent passer avant de soumettre une PR
- Viser une couverture de code > 80%

## Code de Conduite

En participant à ce projet, vous acceptez de respecter notre [Code of Conduct](CODE_OF_CONDUCT.md).

## Questions ?

N'hésitez pas à ouvrir une issue pour toute question !
